## 🧭 Overview
Website for Ink Madrid, a tattoo studio specializing in mandala, comic, realism and biomechanical styles — artist roster, gallery, masterclasses and booking.

## ✨ Features
- Artist roster & gallery
- Tattoo courses / masterclasses
- Booking form
- Location & hours

## 🛠️ Built with
`HTML` · `CSS` · `JavaScript`

# open index.html
